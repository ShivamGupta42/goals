# 2512.13564: Memory in the Age of AI Agents: A Survey — Forms, Functions and Dynamics

1. Problem and claim
- (a) Problem: a fixed LLM cannot be quickly updated, so agents need memory to keep adapting. Claim: agent memory research is fragmented, and a Forms, Functions and Dynamics taxonomy can unify it.
- (b) "whose parameters cannot be rapidly updated"
- (c) Introduction, p.4

2. Mechanism
- (a) Forms: token-level (flat, planar, hierarchical), parametric, latent. Functions: factual, experiential, working. Dynamics: formation (F), evolution (E: consolidate, update, forget), retrieval (R), acting on one memory state. Written at formation, read at retrieval, changed at evolution.
- (b) "selectively transforms these artifacts into memory candidates"
- (c) Section 2.2 (Agent Memory Systems), Memory Formation and Memory Evolution, p.7

3. Evidence
- (a) No experiments of its own and no new numbers. It is a literature review that compiles benchmarks and open-source memory frameworks, mainly in Section 6 (Resources and Frameworks).
- (b) "we compile a comprehensive summary of representative benchmarks and open source memory frameworks"
- (c) Abstract, p.1

4. Limits the authors admit
- (a) Admitted: there may be omissions, since the literature grows fast; readers are asked to report missed papers. Field caveat (Section 5.2.3): overly aggressive pruning risks erasing rare but essential knowledge.
- (b) "we apologize for any such omissions due to the rapidly expanding literature"
- (c) Author note under the title block, p.1

5. (inferred) What a harness like Goals could take from it
1. Split the goal folder by the survey's functions: facts.md (user and environment facts, each with source and date), experience.md (lessons from finished phases), and a scratch file cleared at each phase end (working memory).
2. Retrieval timing: a SessionStart hook loads the plan, open decisions and latest facts; a phase-start prompt tells the agent to pull only experience entries whose tags match the phase.
3. Evolution without deleting: when a new fact conflicts with an old one, a prompt says to mark the old entry "superseded by" the new one, never delete it. This follows the survey's pruning warning.
4. Consolidation at phase close: a prompt or Stop hook reminder asks for one lesson per phase, each linked to its evidence file.
5. Context resets: anything that must survive a /clear or a new session goes into a file, because the chat window is working memory only.
