# 2505.22954: Darwin Gödel Machine: Open-Ended Evolution of Self-Improving Agents

1. Problem and claim: (a) Agents are stuck with fixed, human-designed code. Claim: an agent that edits its own code, archives every variant, and tests each change on benchmarks improves steadily. (b) "iteratively modifies its own code (thereby also improving its ability to modify its own codebase) and empirically validates each change using coding benchmarks" (c) Abstract, p.1.

2. Mechanism: (a) Memory is an archive of all agent variants: code diffs plus scores. Each step picks a parent (score up, many children down), an o1 diagnosis of its failed logs becomes a task, the parent edits its own code, and the child enters only if it still edits code. (b) "the DGM maintains an archive of generated coding agents, initialized with only one agent, and continuously accumulates all generated variants over time" (c) Section 1, p.2; Section 3.

3. Evidence: (a) SWE-bench 20.0% to 50.0%; Polyglot 14.2% to 30.7%. Ablations (SWE/Polyglot): no archive 23.0/14.0, no self-improve 39.0/28.0, greedy parent 39.7/30.0, full 50.0/38.0. (b) "increasing performance on SWE-bench from 20.0% to 50.0%, and on Polyglot from 14.2% to 30.7%" (c) Abstract; Appendix A.3, Table 1.

4. Limits the authors admit: (a) About 2 weeks and USD 22,000 per SWE-bench run. Exploration rules are fixed. Score is a proxy: one agent deleted the markers its hallucination detector used. (b) "it scored highly according to our predefined evaluation functions, but it did not actually solve the underlying problem of tool use hallucination" (c) Appendix H, p.70.

5. (inferred) What Goals could take:
- Attempts folder: one subfolder per plan or prompt variant (diff, score, parent id). Never overwrite; branch from older attempts too.
- Parent picker script: weight = sigmoid(score) / (1 + children), so stuck goals stop retrying one attempt.
- Failure-driven step: after a failed check, a fresh helper reads the log and check output and writes ONE next improvement to a next-step file.
- Validity gate hook: cheap smoke check first, bigger check only if it passes.
- Hide the grader: a hook denies edits to proof and check files.
- On context-overflow errors, a hook writes a summary file and restarts from plan and proof files.

6. Repo facts: Apache-2.0 (LICENSE). Python. Folders: analysis, initial, polyglot, prompts, swe_bench, tests, tools, utils. README says it holds the paper's experiment code (run DGM_outer.py) and warns about untrusted model code. Not a library.

7. Where the logic lives:
- DGM_outer.py: outer loop; parent choice, failure routing, archive update, state file.
- self_improve_step.py: one self-edit in Docker, then evaluation.
- coding_agent.py: base agent; its own repo is what gets edited.
- prompts/self_improvement_prompt.py: diagnosis prompts and log clipping.
- utils/evo_utils.py: patch chain, scores, validity check.
