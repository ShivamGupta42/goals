# 2304.03442: Generative Agents: Interactive Simulacra of Human Behavior

1. Problem and claim: Agents that live for days cannot fit their whole history in the context window. The paper keeps a full text memory stream, retrieves a few relevant records per moment, and adds reflection and planning.
   Quote: "may not make important inferences, and may not maintain long-term coherence". Where: Section 4 (architecture intro).

2. Mechanism: Text records (description, created and last-access times, LLM importance 1-10, embedding). Score = recency (0.995 hourly decay) + importance + relevance (cosine), min-max scaled. Reflection runs when summed importance passes 150 and is stored back with evidence pointers.
   Quote: "The retrieval function scores all memories as a weighted combination of the three elements". Where: Section 4.1.

3. Evidence: Believability (TrueSkill): full 29.89, no reflection 26.88, neither reflection nor planning 25.64, crowdworkers 22.95, no memory 21.21. In a 2-day run, party news spread from 4% to 52% of 25 agents.
   Quote: "Performance degraded with the removal of each component in the ablation conditions". Where: Section 6.5.1 (spread in 7.1.2).

4. Limits the authors admit: Retrieval and place choice worsen as memory grows. Agents embellish or miss memories; memory hacking is untested. The run covered two game days and cost thousands of dollars.
   Quote: "synthesizing an increasingly larger set of memory not only posed a challenge in retrieving the most relevant pieces of information". Where: Section 7.2.

5. (inferred) What Goals could take:
   - Keep `memory.jsonl`: one line per record with id, text, created, last_access, importance 1-10, kind, evidence ids. A hook writes a sentence per step.
   - A resume hook injects only the top N records, scored by time decay + importance + keyword match (grep, no embeddings), then updates last_access.
   - Reflection hook: running importance sum; past a threshold it injects the question and insight prompts and appends results to `reflections.md` with cited ids. Reject reflections lacking evidence ids.
   - At each phase boundary rewrite a short `currently.md` from retrieved records; it survives context resets.
   - Add expiry dates, which the original lacks.

Repo: https://github.com/joonspk-research/generative_agents

   - reverie/backend_server/persona/cognitive_modules/perceive.py: writes events with importance.
